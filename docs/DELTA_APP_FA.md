# مدیریت ساب مشترک دلتا
- /delta فقط مالک ربات مادر با secret_token معتبر. ساب‌های مشترک مستقل از پلن هستند. فقط لینک را بفرستید (۱ تا ۳ در هر پیام، حداکثر ۲۰ لینک ذخیره‌شده). ربات از میزبان مجاز HTTPS دریافت و share-link متنی/Base64 را استخراج می‌کند؛ JSON کامل Xray (شیء یا آرایه) و WireGuard خام نیز پشتیبانی می‌شوند؛ نیازمند APK 1.3.1 یا جدیدتر. خطاهای فرمت و دریافت بدون نمایش محتوای حساس گزارش می‌شوند.
- هر حساب فعال تمام کانفیگ‌های مشترک را دریافت می‌کند. لینک ساب خام به APK ارسال نمی‌شود؛ کانفیگ‌های لازم برای اتصال قابل استخراج هستند. غیرفعال‌کردن ساب و حذف آن در به‌روزرسانی بعدی اعمال می‌شود. برای تغییر کانفیگ یک ساب، دکمه دریافت مجدد را بزنید.
- پلن شامل حجم اسمی، زمان و قیمت است. زمان ورود/نشست در API کنترل می‌شود؛ سقف مصرف واقعی، قطع اتصال جاری و جلوگیری از استفاده بیرون برنامه با کانفیگ مشترک قابل تضمین نیست. برای فروش واقعی نیاز به کنترل ترافیک سمت سرور است. برنامه حجم باقی‌مانده جعلی نشان نمی‌دهد.
- جداول و حساب‌های قدیمی حفظ می‌شوند؛ ساب‌های اختصاصی قبلی به دلایل حریم خصوصی خودکار عمومی نمی‌شوند؛ مالک لینک‌های موردنظر را مجدداً وارد کند. پس از آپدیت ابتدا /delta را بزنید تا مهاجرت انجام شود.
- نصب: همان update.sh گزینه ۷. به فایل پرداخت و سایر داده‌ها دست نمی‌زند. نسخه اندروید جدید لازم است؛ API قدیمی تک‌ساب دیگر استفاده نمی‌شود.

- ساخت کاربر: روی پلن فعال بزنید؛ نام delta + پنج رقم یکتا و رمز تصادفی پنج‌رقمی تولید می‌شود. رمز فقط هنگام ساخت/بازنشانی نمایش داده می‌شود. رمز پنج‌رقمی فقط برای آزمایش مناسب است؛ محدودیت ورود ۵ تلاش در پنج دقیقه و ۲۰ تلاش روزانه به‌ازای نام کاربری اعمال می‌شود (شامل ورود موفق). پیش از فروش عمومی از رمز قوی استفاده کنید.
