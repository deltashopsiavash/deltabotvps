# نسخه اختصاصی پسارگارد (آزمایشی)
- /delta فقط مالک مادر و secret_token. پنل پسارگارد را ابتدا از بخش ثبت پنل فعلی ربات ثبت کنید. سپس در /delta «انتخاب پنل و گروه»، شماره پنل و گروه (مثلاً 1 | 2) را وارد کنید. TLS معتبر، API رسمی /api/admin/token و /api/group/{id} و /api/user لازم است. گواهی نامعتبر پذیرفته نمی‌شود. برای حساب‌های جدید یک پنل/گروه پیش‌فرض تعیین می‌شود؛ حساب‌های قبلی به پنل اصلی خود متصل می‌مانند.
- ساخت حساب از پلن، کاربر مستقل با نام داخلی تصادفی در پنل و یادداشت مالکیت تولید می‌کند؛ حجم GiB=1073741824 بایت، زمان UTC دقیق، no_reset. بعد از تأیید readback فعال می‌شود. وضعیت مبهم شبکه رکورد pending نگه می‌دارد و دکمه بازیابی ساخت دارد؛ رمز جدید بعد از تأیید.
- مصرف و مانده از used_traffic و data_limit اختصاصی پنل خوانده می‌شود. کنترل واقعی در پنل و نودهاست؛ تأخیر گزارش پنل ممکن است وجود داشته باشد. اختلاف حجم/زمان/هویت موجب عدم تحویل کانفیگ می‌شود. ساب فقط از میزبان ثبت‌شده و TLS معتبر دریافت می‌شود.
- حساب‌های مشترک قدیمی و ساب‌های ذخیره‌شده حذف نمی‌شوند ولی API دیگر کانفیگ مشترک تحویل نمی‌دهد. برای تست حساب جدید بسازید. ساب‌ها/شناسه‌های مشترک قدیمی را در پنل با هماهنگی مالک بچرخانید؛ این نسخه نمی‌تواند آن‌ها را باطل کند.
- حذف/غیرفعال کردن ابتدا ورود محلی را می‌بندد و سپس پنل را تغییر می‌دهد؛ حذف محلی فقط پس از تأیید حذف پنل. اگر عملیات پنل ناموفق است، دوباره حذف را امتحان کنید یا در پنل بررسی کنید. تغییر رمز برنامه لزوماً کانفیگ قبلی پنل را revoke نمی‌کند.
- خرید عمومی، تمدید، مهاجرت حساب‌های مشترک، چند پنل همزمان برای یک حساب هنوز پیاده نشده‌اند. پیش از فروش، حساب آزمایشی کوچک، مصرف، اتمام حجم، انقضا و قطع واقعی را روی نودها بررسی کنید. رمز پنج‌رقمی فقط مناسب آزمایش.
- آپدیت با update.sh گزینه ۷؛ ابتدا /delta برای ایجاد جداول. اندروید جدید لازم است.
