تحویل فایل NPV Tunnel در نسخهٔ جدید

نسخهٔ جدید NPV Tunnel به جای قفل Device ID از Public Key استفاده می‌کند.
فایل‌های قدیمی NPVTSUB1 تولیدشده توسط tools/npvtsub-maker برای این نسخه مناسب نیستند.
ربات اکنون Public Key را از مسیر More → My Public Key → Public Key می‌گیرد.

سازندهٔ tools/npvs_public_key.py لینک ساب را بدون تبدیل‌کردن به کانفیگ تکی
در فایل .npvs نسخهٔ ۶ برای Public Key همان کاربر رمزگذاری می‌کند. پایتون
و بستهٔ cryptography لازم هستند؛ هنگام نصب ربات، وابستگی در محیط
/opt/vpsbot/venv نصب می‌شود. اگر محیط جداگانه‌ای دارید، همان بسته را در آن
نصب کنید و دستور سازنده را در settings/npvs_generator_cmd.txt بنویسید.
برای نصب‌های موجود، فقط /opt/vpsbot/venv/bin/pip install 'cryptography>=41,<47'
را اجرا کنید؛ نیازی به اجرای دوبارهٔ نصب کامل ربات نیست.
الگوهای دستور: {root}، {sub}، {public_key}، {out} و {name}.

ربات پیش از ارسال، نسخه، اثر انگشت Public Key، ساختار و امضای فایل را
بررسی می‌کند. اگر ساخت فایل یا ارسال آن ناموفق باشد، سفارش باقی می‌ماند
و مشخصات درخواست برای ساخت دستی به مدیر می‌رسد. سازندهٔ قدیمی Device ID
برای سفارش‌های جدید اجرا نمی‌شود. برای ساخت مجدد سفارش قدیمی نیز ربات
Public Key جدید را از کاربر می‌گیرد.

قالب نسخهٔ ۶ از فایل خروجی برنامه بررسی شده و تست رمزنگاری انجام شده است.
واردکردن فایل خروجی در خود نسخهٔ جدید NPV Tunnel نیز باید یک بار روی گوشی
آزمایش شود؛ ساختار معتبر و امضای درست به‌تنهایی سازگاری برنامه را ثابت نمی‌کند.

هرگز Private Key برنامه را از کاربر نگیرید یا در فایل‌های سرور ذخیره نکنید.
